# Simple E-commerce Website

A fully functional e-commerce website built with HTML, CSS, and JavaScript.

## Features

- 🛍️ Product listing with categories
- 🔍 Search and filter products
- 🛒 Shopping cart functionality
- 💳 Checkout process
- 📱 Responsive design
- 💾 Local storage for cart persistence

## Pages

1. **Home Page** - Featured products and navigation
2. **Products Page** - All products with filtering
3. **Cart Page** - Shopping cart management
4. **Checkout Page** - Order placement
